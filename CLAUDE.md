# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

C++20 / Qt6 Widgets desktop app (Linux): a Scratch-like block editor to program the BatMobile Zumo robot (`../robot_chenillette`) and run the program over classic Bluetooth (SPP/RFCOMM). Sibling of the remote control `../robot_chenillette_pc_qt6`, from which `config.h`, `link.*`, `bluez.*`, `pairing.*`, `bt_pairing.cpp` and the connection part of `window.cpp` are copied unchanged — keep them in sync. UI strings and comments are in French.

Not yet tested with the real robot; checked offscreen (runner output on a socketpair, snapping, JSON round trip, undo/redo, autosave restore, stage positions, zoom anchoring, wheel steps, panning, arrange, ghost insert/remove/drop via synthetic drag events, step mode, every example run in the stage, screenshots). A modal dialog (e.g. `confirmDiscard` with `modified_` set) hangs an offscreen test: reset `modified_` first.

## Build / Run

```bash
./build.sh            # → build/batmobile_scratch + build/bt_pairing
./launchScratch.sh
```

Offscreen smoke test: `QT_QPA_PLATFORM=offscreen`, link the object files with a test program (`#define private public` to reach `Link::fd_`, plug a `socketpair` end in it, `setConnected(true)`), `canvas().load(json)`, `run(canvas().startScript())`, pump events while `runner().isRunning()`. Exit with `QCoreApplication::exit()`, not `quit()` (closing opens the modal confirmation). Call `QStandardPaths::setTestModeEnabled(true)` (and set the application name) so the test does not overwrite the user's autosave.

## Architecture

- **`blocks`** — `Kind`, the `Specs` table (text with `%1` / `%2` inputs, `%v` variable list, `%n` name text; color, `Shape`, one `Param` for all inputs, command char, two defaults) in enum order, palette `categories()`. `Block` = linked list (`next`) + `body` for loops + `inputs[2]` (a number, or a `Shape::Reporter` block in `Input::reporter`) + `name` (variable), all owned by `unique_ptr`. Value clamp/format/parse (comma decimal). JSON per block: `value`/`value2`, `arg`/`arg2` (reporter object), `name`, `body`; `blocksFromJson` drops a hat not at the top, a reporter that is not a lone script, and anything after a `CapC`. `collectVariables()` lists names used in a stack.
- **Conditions** — `Shape::Boolean` (hexagon) reporters (`Less`, `Equal`, `Greater`, `And`, `Or`, `Not`) go only into `Param::Bool` inputs (`acceptsShape`), numeric `Shape::Reporter` only into numeric ones; an empty Bool input is drawn as a hollow hexagon (`Item::value[i]` set for hit/snap, not editable, no JSON value) and is false. `If` / `RepeatUntil` are C blocks, `IfElse` is `Shape::E` with `Block::body2` (`"body2"` in JSON, `Item::elseTop`, `elsePath()`, « sinon » row of `ElseH`).
- **`blockview`** — geometry and painting shared by palette and canvas: `layout()` places a stack recursively into `Item`s (pre-order = paint order; input reporters right after their block) with the owning `slot` (`BlockPtr *`: `next`, `body`, `Script::top` or `Input::reporter`) so any block can be detached; Scratch shapes (notch/tab, hat dome, C, rounded reporter). Text is split into tokens (`placeTokens`, also used by `measure`); the row height (`Item::rowH`) grows to fit nested reporters, so C arms and loop bodies use `rowH`, never the `RowH` constant. `Item::value[i]` = literal pill of input i (null when a reporter fills it), `Item::var` = variable list. `drag()` / `fromMime()`: every drag is a `QDrag` carrying the stack as JSON + hot spot.
- **`examples/*.batmobile`** — example programs compiled in as Qt resources (`:/examples/…`, `qt_add_resources` in CMake), listed in `Examples` in `window.cpp`. They use the cm / degree blocks, so they follow the calibration (Danse keeps durations for its rhythm). Durations have 2 decimals (`Range` in `blocks.cpp`; display trims to ≥ 1 decimal).
- **Key hats** — `Kind::KeyHat`, `Param::Key` whose value is an index into the key list (`keyName` / `keyIndex` in `blocks.cpp`, by `Qt::Key` so independent of AZERTY/QWERTY); the pill opens a menu (`Canvas::chooseKey`). `Window` installs an application event filter: a plain key press (no Ctrl/Alt/Meta, no auto-repeat, not in a `QLineEdit`, no popup) with a matching `Canvas::keyScript()` runs it via `runKeyScript()` without resetting the speed; a new key replaces a running key script, ▶ / step-mode runs ignore keys (`keyRun_`).
- **`Palette`** — template blocks; dragging copies the template through JSON (keeps the variable name). `rebuild()` on `setVariables()`: fixed categories, then a Variables section (« Créer une variable » button → `createVariableRequested`, one `Variable` reporter per name, set/change on the first name; right-click a variable → `deleteVariableRequested`), then Mes blocs (« Créer un bloc » → `createBlockRequested`, one `Call` per defined name); sections are built generically (heading, optional button, templates); emits `widthChanged` for the scroll area. Accepts drops from the canvas = delete. Search (`setFilter`, the `search` line edit above it): accent- and case-insensitive match on each template's label, only matching sections shown, no buttons, collapsing ignored; a click on a heading toggles `collapsed_` (session only). The width is computed from all templates so it does not change while filtering.
- **`Canvas`** — `Script { pos, top }` in `vector<unique_ptr>` (stable addresses). Drag: detaches block + followers (`std::move(*slot)`), runs `QDrag`; `IgnoreAction` → put back into the slot. Never prune empty scripts during a drag (the slot may be a `Script::top`). `findSnap`: after a block, inside a loop body, or above a non-hat script (within 30 px). Click on a value → `QLineEdit` overlay; click elsewhere → `scriptClicked(script top)`, double-click → `scriptDoubleClicked`: the window runs on a single click only when the robot is not connected (otherwise a status hint), on a double-click always. `setRunning(true)` blocks structural edits because the `Runner` holds raw `Block*`.
  - **Ghost preview** — during a drag over the canvas, `dragMoveEvent` removes the previous ghost, runs `findSnap` on the clean model, then `showGhost`: a slot snap really inserts `incoming_` into the model (`ghostSlot_` / `ghostTail_`, painted gray via `ghostBlocks_`, followers pushed down); an above-script snap only lays out `ghostItems_`. `removeGhost()` gives the stack back to `incoming_`; `dropEvent` removes it then calls `drop()`; `endDrop()` runs on leave and after `QDrag::exec`. While a ghost is inserted, `edited()` is a no-op and `Window::autosave()` postpones (`hasGhost()`).
  - **Zoom / pan** — model coordinates (scripts, `Item`s, `pressPos_`, mime hot spot) are unzoomed; `paintEvent` scales by `zoom_`, every event position goes through `toModel()`, the minimum size and the value editor are scaled, the drag pixmap is rendered at `zoom_`. `setZoom()` keeps the anchor under the mouse: `sendPostedEvents(LayoutRequest)` so the `QScrollArea` (found by `scrollArea()`) applies the new size before the scroll bars are set. Background drag (or middle button) pans the scroll bars with global positions.
  - **Wheel on a value** — `stepValue()` changes it immediately, `wheelCommit_` (600 ms) records one history step; `commitEdit()` flushes it first, so undo/press/drag never lose it. Plain wheel elsewhere is ignored so the scroll area scrolls; Ctrl+wheel zooms.
  - **Background menu** — « Ajouter un commentaire », `arrangeScripts()` (column at `FirstScript.x`, top-to-bottom order; comments stay put) and `removeAll()` (scripts and comments), all undoable.
  - **Reporters / variables** — `findSnap` for a reporter only considers free inputs accepting reporters (`acceptsReporter`), near the pill's left-middle; the same slot/ghost/drop code then inserts it into `Input::reporter`. Stacks never snap to reporters. `variables_` is saved as `"variables"` and completed with the names used by the scripts (`setVariables`); `addVariable` / `removeVariable` (refused while used) go through history; `variablesChanged` feeds the palette and the stage monitors. Clicking `var` opens `chooseVariable()`.
  - **Selection / clipboard** — `Block::id` (session-unique counter, not saved) identifies blocks across relayouts; `selection_` holds ids (cleared by `clear()` / `restore()`, stale ids are ignored), set by press (Ctrl toggles, background clears), painted as a blue halo under the selected stacks (`collectStack`). `selectionRoots()` drops blocks already inside another selected stack. Copy puts `{"scripts": [{x, y, blocks}]}` (positions relative to the selection) under `application/x-batmobile-scripts` in `QClipboard`; paste adds them as new scripts under the mouse (or near the view centre) and selects them; Cut / Delete detach each root through its slot. Window shortcuts: standard Copy / Cut / Paste / Delete / SelectAll (a focused `QLineEdit` / `QPlainTextEdit` keeps them).
  - **Text field** — token `%t` (`Say`, `SayFor`): `Block::text` (JSON `"text"`) shown in `Item::textField`, edited with the value editor (`editedInput_ == EditText`), or replaced by any reporter shape in `inputs[TextInput]` (JSON `"arg2"`, snapped by `findSnap` regardless of `Param`).
  - **Mes blocs** — `Kind::Define` (hat « définir %n ») and `Kind::Call` (« %n »), both using `Block::name` and `Block::params` (≤ `MaxParams` = 2, JSON `"params"`); a call has one `Param::Number` input per parameter (`inputCount(const Block *)`, `tokens()` built per block), `Kind::ParamValue` reporters read them. `Procedure { name, params }`. `updateProcedures()` (after `edited()`, `restore()`, `clear()` — not in `relayout()`, so a drag does not rebuild the palette) lists define names top to bottom and emits `proceduresChanged` → `Palette::setProcedures`. `addProcedure()` places a define hat below all scripts. `procedure(name)` = topmost define.
  - **Comments** — yellow notes (`Comment { rect, text, blockId, offset }` in `comments_`, model coordinates), saved as `"comments"` (`x, y, w, h, text`, and for an attached note `block` = index in `allBlocks()` order plus `dx, dy`, remapped to the new ids on `restore()`). `placeAttachedComments()` (in `relayout()`) moves an attached note to its block's item + offset, and deletes it when the block is gone unless the block is being dragged (`dragIds_`); an internal drag drops the original stack (`dragStack_`) so ids — and notes — survive; a connector line is painted from the block's row to the note, included in `relayout()` bounds and its shift, painted above the blocks and hit first. Press on a note raises it; past the drag distance it moves, on the bottom-right grip it resizes, a plain click opens the `QPlainTextEdit` overlay (`editComment`); `commitComment()` (called by `commitEdit()` and on focus-out through `eventFilter`) records one history step. Notes stay editable while running. `Window::eventFilter` ignores key scripts while a `QPlainTextEdit` has the focus.
  - **History** — every modification goes through `edited()`, which appends the full `save()` JSON to `history_` (deduplicated, max 200); `undo()` / `redo()` `restore()` a state. `load()` / `clear()` reset the history and `saved_`; `isModified()` = current state ≠ `saved_` (so undoing back to the saved state clears the `*`). Undo is disabled while running.
- **`Runner`** — timer-driven interpreter (no threads, `Qt::PreciseTimer`), frame stack for loops. Timed block: send cmd, wait, send `Stop`. A loop iteration with no wait yields (`MinWaitMs`) so ■ keeps working. Sends `SpeedLevelDefault` at start; `stop()` sends `Stop`. Every command also goes out as `sent(char)`. Cm / degree blocks (`ForwardCm`… with `Param::Distance` / `Param::Angle`) wait `calibration_.duration(motion, speedLevel_, amount)`; `speedLevel_` follows the digits sent (default at start, kept by key scripts). Inputs are read with `input(b, i, Param)` (number or `evaluate(reporter)`, then clamped for its use); `vars_` keeps variable values across runs (`resetVariables()` when a program is loaded), `setVariable` rounds to 0.01 and emits `variableChanged`. A lone reporter clicked shows its value (`Window::showValue`). `Call`: the window gives `setProcedures(lookup)`; a call evaluates its inputs in the caller's context and pushes a frame `{define->next, loop = nullptr, args, call = true}` (popped like a script end); `ParamValue` reads `args` of the nearest call frame (`argument()`), skipped if the name is unknown; over `MaxDepth` (1000) frames the run stops and emits `error`. Step mode does not pause on `Call` (only on the blocks of the definition). `Say` emits `said(text)`; `SayFor` also sets `saying_`, cleared (empty `said`) when its wait ends; `start()` and `stop()` clear the bubble (`Stage::setSpeech`). `If` / `IfElse` push the chosen body as a frame without loop; `RepeatUntil` is a loop frame whose end-of-body test is `!condition()` (checked before each turn, also on entry); `condition()` = reporter value ≠ 0, empty = false; comparisons use 1e-9 for `=`. `Go*` blocks (`Param::None` with a `cmd`) send without waiting and set `rolling_`; `stopRolling()` sends `Stop` at the natural end of the program and before a step-mode pause (any `Stop` sent clears `rolling_`). Step mode (`start(first, true)`): `step()` pauses (`paused_`, `paused(next)`) before each action block (not Start/Repeat/Forever) once one has run since the last `resume()`; `resume(true)` runs one more, `resume(false)` continues; `stop()` works while paused.
- **`Calibration`** — per motion (forward, backward, left, right) and speed level: `Rate { perS, t0 }` (cm/s or °/s, and start-up time lost to the firmware ramp, straight lines only). Measured levels in `measured_`; others interpolated linearly, or scaled with the motor speed beyond the measured range; defaults 0.1 cm/s and 0.9 °/s per motor unit, t0 = half the ramp (`v / 1000` s). Straight model: `d = perS (t − t0)` after the ramp (`t ≥ 2 t0`), `perS t² / (4 t0)` during it; `duration()` / `amount()` invert each other. `fromStraight(d1, d3)` from the 1 s / 3 s trials. Saved as JSON in `AppDataLocation/calibration.json` (`Window::calibrationPath`), loaded at start, applied to the runner and the stage (`applyCalibration`).
- **`CalibrationDialog`** — non-modal assistant (⚙ Calibrer… under the stage): motion + speed level; straight page (Lancer 1 s / 3 s, measured distances, Calculer et enregistrer), turn page (adjust the duration of a full turn, Enregistrer); table of the values used per level. `trialRequested` → `Window::runTrial` runs a temporary program (`trial_`: vitesse N → timed block) through `startRun`; `calibrationChanged` → saved and applied.
- **`Stage`** — top-down simulation fed by `Runner::sent` (same protocol as the robot), world in cm (field 160 × 120 cm drawn on 480 × 360 units, `UnitsPerCm = 3`, 10 cm grid, robot drawn at `RobotDrawScale`): straight lines integrate the calibrated ramp exactly (`drive()`: signed `velocity_` towards ±perS with acceleration perS / 2 t0; any other command stops it), pivots at the calibrated °/s; nanosecond `QElapsedTimer` (ms `restart()` truncation lost ~3 %), 16 ms frames only while moving. Variable monitors (`setMonitors`) top-left. Claw: `drawJaws()` (hooked jaws) on the robot and in a bottom-left close-up shown while `c` / `v` is active (`clawZoom_`), kept `ClawZoomHoldMs` then faded over `ClawZoomFadeMs`; the frame timer keeps running after a stop until the close-up is gone (`tick()`).
- **`Window`** — header (devices, connect, ▶ F5, ⏭ F10, ■), `runOrContinue()` starts or resumes a paused run, palette | canvas | stage, undo/redo, zoom, Exemples ▾ (`openExample()`: no file name, title from `untitled_`, also autosaved) + file buttons, ✕. Esc = stop. Link lost / disconnect / close stop the runner. Unsaved changes asked on New/Open (not on Quit: autosave). Plus ▾ (`fillMoreMenu`, rebuilt on each click): recent files (`recentFiles_`, absolute paths, max 8, `addRecent` on open / save, kept in `AppDataLocation/settings.json`) and `exportImage()` → `Canvas::renderImage()` (items + `paintComments()` on white, scale 2). **Autosave**: 1 s after each change and on close, `QSaveFile` to `AppDataLocation/autosave.batmobile` with `{program, saved, fileName}`; restored in the constructor.

## Command Protocol

Same as the remote control and the firmware: `z s q d` move, `v c` claw, `w x` head (held until `' '`), `0`–`9` speed `(n + 1) × 40`, `' '` stop. No keep-alive in the firmware: every command that moves must be followed by a stop, and the safety stops (■, Esc, disconnect, close, link loss) must stay.
